##  Descripción General

Este repositorio contiene el código fuente, la planificación y la documentación de nuestro Trabajo Final Interdisciplinario.

El proyecto consiste en el desarrollo de un videojuego web multijugador interactivo en tiempo real. Estamos realizando la migración y modernización de un prototipo previo utilizando tecnologías de desarrollo web moderno como **React** y **Next.js**, e integrando **WebSockets** para permitir la jugabilidad simultánea entre múltiples usuarios.

---

## Asignaturas Involucradas

El proyecto integra los contenidos y metodologías de tres asignaturas técnicas del plan de estudios:

* **Proyectos de Producción** (4 hs)
* **Desarrollo de Aplicaciones Informáticas** (4 hs)
* **Seminario** (2 hs)

---

##  Tecnologías Utilizadas

* **Frontend:** React, Next.js, HTML5, CSS3 / Tailwind
* **Backend & Tiempo Real:** Node.js, WebSockets (Socket.io)
* **Control de Versiones:** Git & GitHub

---

##  Alcance y Objetivos

* **Funcionalidad y Estabilidad:** Entregar una plataforma totalmente funcional, libre de errores o fallos de ejecución.
* **Experiencia Multijugador:** Permitir partidas fluidas y simultáneas para 2 o más jugadores en tiempo real.
* **Interfaz de Usuario (UI/UX):** Diseñar una interfaz dinámica, responsiva y con animaciones integradas para ofrecer una experiencia atractiva e intuitiva.
